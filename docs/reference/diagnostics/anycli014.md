# ANYCLI014: Duplicate option name

| Property | Value |
| --- | --- |
| Rule ID | `ANYCLI014` |
| Title | Duplicate option name |
| Category | `AnyCli` |
| Diagnostic type | Source generator |
| Enabled by default | Yes |
| Default severity | Error |
| Code fix available | No |

## Cause

An option name or alias is reused within the parameter type.

## Resolution

Make every option name and alias unique.
